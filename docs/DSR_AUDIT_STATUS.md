# Dark Souls Remastered audit status

This note records project scope without redistributing game text or assets.

## Prior private work

The local initiative explored extracted English item/menu text, proposed terminology changes, and several interaction/emote substitutions for the owner’s installation. The player reported that the revised interaction appeared as intended in a screenshot. That is a limited user-observed check, not comprehensive validation of the game, every quest state, locale, animation context, or current build.

## What remains unverified

- Complete coverage of all English dialogue, subtitles, item text, events, environmental assets, cutscenes, audio, gestures, and visual symbols.
- Other supported languages and game updates.
- Whether every altered interaction remains appropriate in all contexts.
- Publisher authorization and account-policy safety for distributing or using a modified build.
- Full game-wide religious suitability. The scanner and the previous manual pass cannot certify that no relevant content remains.

## Public release boundary

This GitHub project publishes only original scanner code, its project-authored lexicon, a fictional sample CSV, and documentation. It does not include DSR binaries, extracted strings, assets, save data, loaders, or an installable DSR package. The official Steam [EULA](https://store.steampowered.com/eula/570940_eula_0) contains restrictions relevant to reverse engineering and modifications. Check current official terms before any game-specific activity. No claim of offline or online ban immunity is made.
